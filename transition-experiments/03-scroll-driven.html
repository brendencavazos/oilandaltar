3. CSS scroll-driven animation + hover + lightbox

Reveal driven by animation-timeline: view() where the browser can, with a watchdog that switches to JavaScript the moment it detects the timeline isn't actually driving the tiles. Hover pushes a frame in; click opens the full overlay; arrows step through all 45.

Inside the overlay: ← → to move, Esc to close. Add ?debug=1 to the URL for a live readout of which reveal path is running.
