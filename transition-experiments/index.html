Bible Belt — transition experiments

Nine ways the same 45 photographs could arrive on screen. Each page rebuilds the real Bible Belt mosaic from the live image files, with one effect applied, so they can be compared like for like.

Nothing here touches the site. These are standalone pages in /transition-experiments/; the live pages are unchanged.

Adds ?rm=1 to the links below — every variant then behaves as it would for a visitor who has "reduce motion" switched on in their OS.
  1. 01
    Fade-in on scroll

    Frames fade and rise 14px into place as they enter the viewport. 520ms.

    Universal support. The safe default.

  2. 02
    Staggered reveal

    The same reveal, cascaded 60ms apart so a row arrives in sequence.

    Universal support. Delay capped at 300ms so fast scrolling never waits.

  3. 03
    CSS scroll-driven animation + hover + lightbox

    Reveal tied to scroll position by animation-timeline: view() with no JavaScript, plus hover zoom, click-to-expand overlay, and arrows to step through all 45.

    Chrome/Edge 115+, Safari 26+ for the reveal; falls back to variant 01 elsewhere. The overlay works everywhere. Closest thing here to a finished experience.

  4. 04
    Crossfade rotation

    Six tiles slowly trade between two photographs on a 7s cycle, offset so they never change together.

    Universal. Doubles the image requests for those six tiles; pauses in background tabs.

  5. 05
    Ken Burns

    Continuous slow pan and zoom, scale 1 → 1.06 over ~26s, alternating.

    Universal, but the heaviest here: only on-screen tiles animate, and it still keeps the GPU busy. Watch battery on laptops.

  6. 06
    Hover zoom + brightness

    Scale 1.035 and a small brightness lift on hover, 320ms. Keyboard focus gets it too.

    Universal. Touch devices get a press state instead, via @media (hover: hover).

  7. 07
    Lightbox transition

    Click expands into a full-view overlay: backdrop fades, photograph scales from 0.96.

    Universal. Closest to what the site does today. Full-size file loads only on open.

  8. 08
    Shared element transition

    The clicked frame morphs into the large view — one continuous photograph, not a fade.

    Chrome/Edge 111+, Safari 18+. Degrades to variant 07 elsewhere; the page reports which.

  9. 09
    Blur-up loading

    The existing thumbnail shows blurred, then sharpens as the full-size file arrives.

    Universal. Heavier than the live site — it fetches the 2000px file per tile rather than the thumbnail.
